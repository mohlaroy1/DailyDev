while developing better software engineering habits.

## Architecture

### Core Models

**Technology**

Represents a programming language, framework, database, or tool.

**CodingSession**

Represents a coding session and stores:

- What was built
- Description of the work
- Date
- Coding duration
- Technologies used
- Related GitHub commit
